🤖 Instagram Auto Reels Automation

AI-Powered Instagram Reels Creation & Publishing System

An automated Instagram Reels workflow designed to research trending topics, generate Hindi scripts, create AI voiceovers, edit videos, add subtitles, and publish Reels using GitHub Actions.

🚀 Project Features

- 🔍 Automatic trending topic research
- 🧠 Google Gemini AI script generation
- 🎙️ Hindi Text-to-Speech voice generation
- 🎬 Automatic video editing using FFmpeg
- 📝 Hindi captions and subtitles
- 🔤 Noto Sans Devanagari font support
- ☁️ GitHub Actions cloud runner
- 📤 Instagram Reels publishing through Instagram Graph API
- 🔐 Secure API credentials using GitHub Secrets
- 📅 Target: 3 Reels per day

🛠️ Technologies

Technology| Purpose
GitHub Actions| Automation runner
Python 3.11| Workflow programming
FFmpeg| Video editing
Google Gemini API| AI script generation
Hindi TTS| Voice generation
Instagram Graph API| Reel publishing
Noto Sans Devanagari| Hindi text rendering

⚙️ Setup Requirements

1. GitHub account
2. Google Gemini API key
3. Instagram Professional Creator account
4. Instagram Graph API access
5. FFmpeg
6. Python 3.11
7. Public HTTPS video hosting

🔑 GitHub Secrets

Configure these secrets under:

Settings → Secrets and variables → Actions → New repository secret

- GEMINI_API_KEY
- IG_USER_ID
- IG_ACCESS_TOKEN
- VIDEO_HOST_TOKEN

Never publish API keys or access tokens publicly.

▶️ GitHub Actions

The workflow can be started from:

Repository → Actions → Instagram Reels Automation → Run workflow
